# مدرسة العالمين

منصة امتحانات ودرجات وحضور. للنشر على Vercel مع قاعدة بيانات Postgres (مثلًا Neon).

## المتغيرات المطلوبة (Environment Variables)
- `DATABASE_URL`: رابط قاعدة البيانات (postgresql://...).
- `BETTER_AUTH_SECRET`: نص عشوائي طويل (32 حرف أو أكتر).
- `BETTER_AUTH_URL`: رابط الموقع بعد النشر، مثل https://اسم-مشروعك.vercel.app

## أول تشغيل
أول حساب يتسجّل من صفحة الدخول بيبقى المدير. سجّل بيه بنفسك قبل ما تشارك الرابط.
جداول قاعدة البيانات بتتجهّز تلقائيًا أثناء البناء (npm run build).
